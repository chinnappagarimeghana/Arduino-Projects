# 🤖 Arduino Projects

A portfolio of robotics and embedded systems projects developed using Arduino UNO and NodeMCU ESP8266. This repository showcases practical implementations of motor control, wireless communication, sensor interfacing, and autonomous navigation through a collection of hands-on projects.

---

## 📂 Projects

### 🚗 Line Follower Robot

An autonomous robot that follows a predefined path using infrared sensors and a motor driver.

**Highlights**

* IR sensor-based line detection
* Autonomous navigation
* Real-time path correction
* Motor control using L293D

---

### 📱 Bluetooth Controlled Robot

A wireless robot controlled through a smartphone using Bluetooth communication.

**Highlights**

* HC-05 Bluetooth module integration
* Mobile-based control
* Forward, backward, left, and right movement
* Real-time wireless operation

---

### ⌨️ Keypad Controlled Robot

A robot controlled using a 4×4 keypad directly connected to the Arduino.

**Highlights**

* Keypad interfacing
* Directional navigation
* User-controlled movement
* Embedded input processing

---

### 🌐 NodeMCU WiFi Controlled Robot

A WiFi-enabled robot controlled over a local network using NodeMCU ESP8266.

**Highlights**

* WiFi-based control system
* Web server implementation
* Wireless robot navigation
* ESP8266 integration

---
